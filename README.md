# 📋 할일 정리

`G:\바탕화면\★할일★` 폴더를 노션처럼 **그룹별 목록**으로 보여주는 창 프로그램.

## 실행 방법
**`dist\할일정리\할일정리.exe` 더블클릭** — 그게 전부입니다.
(exe에 대한 바로가기를 만들어 바탕화면이나 작업표시줄에 두면 편해요)

`dist\할일정리\` 폴더 전체(exe + `_internal` 폴더)가 한 세트입니다. 옮기려면 폴더째로 옮기세요.
- `_internal` 폴더에는 프로그램 실행에 필요한 라이브러리와 화면(web/index.html)이 들어있습니다. 지우거나 따로 옮기면 실행이 안 됩니다.
- `data.json`(그룹/순서/메모/마감일 등)은 exe와 같은 폴더에 자동 생성·저장됩니다.

### 개발용 실행 (소스 코드로 바로 실행)
`할일정리 실행.bat` 더블클릭 — Python + pywebview가 설치되어 있어야 합니다.

### exe 다시 빌드하기
`app.py`나 `web/index.html`을 수정한 뒤 **`build.bat` 더블클릭**하면 `dist\할일정리\`가 새로 만들어집니다.
(단일 파일(onefile)이 아니라 exe + `_internal` 폴더 구조로 만들어서 실행 속도가 훨씬 빠릅니다.)

- 재빌드 시 `dist\할일정리\data.json`(그룹/상태/메모 등)은 자동으로 백업했다가 빌드 후 복원합니다. 별도로 신경 쓸 필요 없어요.
- 실제 빌드 로직은 `build.ps1`에 있고, `build.bat`은 그걸 실행하는 역할만 합니다. exe 실행 중이면 먼저 꺼주세요 (파일이 잠겨서 빌드가 실패할 수 있어요).

## 동작 방식
- 실행할 때마다 `★할일★` 폴더를 자동 스캔합니다.
  - 1단계 폴더(★발주, ★검사검수…) = 카테고리, 2단계 폴더 = 업무 1건
  - **새 업무 폴더를 만들면** 다음 실행/새로고침 때 자동으로 목록에 나타납니다.
  - **업무 폴더를 개인 하드로 옮기면** 목록에서 자동으로 사라집니다. (지금 하던 방식 그대로)
- 그룹, 순서, 메모, 마감일, 상태는 클릭/입력 즉시 `data.json`에 저장됩니다 (지연 저장 없음). 폴더 자체는 절대 건드리지 않습니다.
- ⚠️ **exe 버전과 개발용(소스 실행) 버전은 서로 다른 `data.json`을 씁니다** (각자 자기 폴더 옆에 저장). 평소엔 exe만 쓰시면 되고, 개발용은 저와 함께 기능을 테스트할 때만 쓰는 용도예요.

## 사용법
| 하고 싶은 것 | 방법 |
|---|---|
| 폴더 열기 | 업무 이름 클릭 |
| 폴더 내용 미리보기 | 업무 왼쪽 ▾ 클릭 (파일 클릭 시 바로 열림) |
| 순서 바꾸기 / 그룹 이동 | 왼쪽 ⠿ 핸들을 끌어서 놓기 |
| 상태 바꾸기 | 상태 배지 클릭 (대기→진행중→급함→완료 순환) |
| 마감일 | 📅 클릭 → 날짜 선택 (D-day 자동 표시, 임박·초과 시 색 변경) |
| 메모 | 메모 영역 클릭 → 입력 → Enter |
| 그룹 추가/이름변경/삭제 | 상단 ＋그룹 추가 / 그룹명 클릭 / 그룹 ✕ |
| 검색 | 상단 검색창 (업무명 + 메모 검색) |
| 정렬 방식 변경 | 상단 정렬 드롭다운 (사용자 지정/이름순/마감일순/상태순/최근 수정순/파일 많은순) |
| 테마 전환 | 상단 🖥️/☀️/🌙 버튼 클릭 (시스템 설정 따름 → 라이트 → 다크 순환) |
| 할일 폴더 경로 변경 | 상단 경로 클릭 |
| 항상 위에 표시 | 타이틀바 📌 클릭 (다른 창 위에 계속 떠 있음) |
| 최소화 | 타이틀바 ─ 클릭 (작업표시줄로) |
| 닫기(트레이로 숨김) | 타이틀바 ✕ 클릭 — 프로그램은 계속 실행되고 트레이 아이콘으로 숨어요 |
| 다시 열기 | 시스템 트레이(작업표시줄 우측 하단 숨김 아이콘) 📋 아이콘 클릭 |
| 완전 종료 | 트레이 아이콘 우클릭 → 완전 종료 |
| 창 이동 | 타이틀바(맨 위 얇은 줄) 끌기 |
| 창 크기 조절 | 우하단 모서리 ◢ 끌기 |

- 화면 가장자리(위/아래)로 업무를 끌고 가면 자동으로 스크롤됩니다.
- **사용자 지정 순서**일 때만 드래그로 순서를 바꿀 수 있어요. 다른 정렬을 고르면 보기 순서만 바뀌고, 사용자 지정으로 되돌리면 원래 순서가 그대로 남아있습니다.
- 정렬 방식과 테마 설정은 이 컴퓨터에 저장되어 다음 실행에도 유지됩니다.
- 창은 위젯처럼 OS 타이틀바 없이 떠 있고, `✕`로 닫아도 완전히 꺼지지 않고 트레이에 상주합니다. 완전히 끄려면 트레이 아이콘을 우클릭해서 "완전 종료"를 눌러야 합니다.

## 요구 사항
- Python 3 + `pywebview`, `pystray`, `Pillow` — 이미 설치됨 (`pip install pywebview pystray Pillow`)
